Tu progreso

Sí. Las partidas quedan guardadas en el almacenamiento privado de este navegador, en la computadora o el celular donde se juega. No se suben a ningún servidor.

  • Borrar los datos de este sitio en el navegador también borra las partidas.
  • Para tener una copia: Files and saves → Manage → Export saves descarga un ZIP.
  • Ese ZIP se puede importar en otro navegador o restaurar más adelante.
